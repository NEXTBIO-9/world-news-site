NEXT BIO 긴급속보 티커 최종 통합 (지도 바로 아래)

1. ZIP 압축을 풉니다.
2. nextbio-emergency-ticker.js, scripts/, data/, .github/ 폴더를 저장소 최상단의 동일 경로에 업로드합니다. 기존 같은 파일은 덮어씁니다.
3. index.html 끝의 </body> 바로 앞에 다음 줄이 있는지 확인합니다.
   <script src="./nextbio-emergency-ticker.js?v=2" defer></script>
   이미 v=1 줄이 있으면 v=2로 변경만 합니다. 두 줄 중복 추가하지 마세요.
4. 이전에 nextbio-ticker-position.js를 추가했다면 index.html의 해당 script 줄은 삭제해도 됩니다. 이 버전은 별도 위치 수정 스크립트가 필요 없습니다.
5. GitHub Commit changes 후 배포를 확인하고 Ctrl+F5로 새로고침합니다.

주의: 공식 지진 검증 및 수동 검토 긴급속보만 표시합니다. 일반 뉴스는 주요뉴스로 표시합니다. GitHub Actions 실행 주기는 GitHub 스케줄 지연의 영향을 받습니다.
