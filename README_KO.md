# NEXT BIO 2.3 글로벌 상황실

기준: NEXT BIO 2.2의 지도 및 뉴스 기능을 보존하고 화면 배치만 개편.

- 세계지도를 첫 번째 주요 섹션으로 배치, PC에서는 지도 75% / 국가별 뉴스 25%
- PC 지도 높이 약 70vh (최소 560px, 최대 900px)
- 모바일에서는 지도 우선, 그 아래 국가별 뉴스
- 뉴스 분석(속보, 바이오, 날짜, 히트맵, 북마크, 한영 전환)은 지도 아래로 이동
- 최신 뉴스피드는 그 아래 보조 영역
- 자동 국가 순회(9초/국가), 15분 예약 수집 유지
- 인기 키워드 및 주요 헤드라인 제거 상태 유지

## 설치
1. 현재 정상 버전을 별도 브랜치나 ZIP으로 백업하세요.
2. 이 ZIP을 압축 해제하고 폴더 구조를 유지하여 저장소에 업로드하세요.
3. .github/workflows/update-news.yml 경로가 유지되었는지 확인하세요.
4. 기존 data/articles.json은 덮어쓰지 마세요. 이 ZIP에는 포함하지 않았습니다.
5. GitHub Pages 배포가 성공한 뒤 지도/마커/자동 순회/뉴스피드/모바일을 확인하세요.

참고: GitHub Actions 15분 cron은 실행 요청 주기이며 정확한 반영 시각은 보장되지 않습니다.
브라우저 실제 실행 및 GitHub Pages 배포는 아직 검증하지 않았습니다.
