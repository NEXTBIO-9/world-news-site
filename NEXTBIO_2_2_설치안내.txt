설치:
1. 현재 GitHub main 브랜치를 백업하세요.
2. ZIP 압축을 풀고 내부 파일 및 .github 폴더를 저장소 루트에 업로드하세요.
3. 기존 파일을 덮어쓰고 Commit changes 합니다.
4. GitHub Actions의 뉴스 수집 및 Pages 배포 완료 후 Ctrl+F5로 확인합니다.

참고: 15분은 예약 실행 간격입니다. GitHub Actions 지연과 RSS 공급자 갱신 주기에 따라 실제 기사 반영 시간은 다를 수 있습니다.
자동 순회는 현재 사이트에 로드된 최신 기사들을 순회합니다. 백그라운드에서 새 기사 자동 수신을 뜻하지 않습니다.
